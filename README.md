# Sultan Alharbi — Personal Portfolio

Responsive bilingual Arabic/English personal portfolio using plain HTML, CSS and JavaScript.

## Files
- `index.html`: page content and structure
- `style.css`: responsive dark technical visual design
- `script.js`: language switch, mobile menu and LinkedIn-copy interaction
- `favicon.svg`: site icon
- `images/sultan.jpeg`: add your profile photo here

## Run locally
Open `index.html` in a browser or use the Live Server extension in VS Code.

## Publish with GitHub Pages
1. Create a public GitHub repository named exactly `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder (not the enclosing folder) to the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch, branch `main`, folder `/(root)`, then Save.
5. After deployment, visit `https://YOUR-USERNAME.github.io`.

## Before publishing
- Add your photo at `images/sultan.jpeg`.
- Verify the certificate names and dates against your actual certificates.
- Add verified certificate URLs/images only after checking them.
- Do not upload private data or passwords to a public repository.
