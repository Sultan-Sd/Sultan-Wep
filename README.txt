SULTAN ALHARBI PERSONAL PORTFOLIO

Files:
- index.html: page content and bilingual text
- style.css: layout, colors, responsive styles
- script.js: language selection, mobile menu, back-to-top, current year
- favicon.svg: SD site icon

Run locally:
1. Keep all four files in the same folder.
2. Open index.html in a browser.
3. To edit content, change the paired data-ar and data-en values in index.html.
4. Update the LinkedIn href in index.html to your actual public profile URL before publishing.
5. Review the skills and event sections; replace placeholders with verified details before publishing.

The language is initially detected from the browser language. A manual language selection is saved in localStorage when available.
